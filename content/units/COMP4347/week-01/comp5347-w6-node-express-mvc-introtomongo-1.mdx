## Summary

This Week 6 lecture refactors a flat Express app into proper MVC with modular routers/controllers and introduces MongoDB — the architecture and persistence layer of the server-side block.

- Application folder structure: `app/controllers`, `app/routes`, `app/views`, with a thin entrypoint wiring middleware and routers.
- CommonJS modules: `require()` loads, `module.exports`/`exports` expose; one file = one module.
- Controllers as exported handler functions; routers binding URL+verb to controller methods (`router.get('/path', ctrl.method)`).
- Variable scopes in Express: application scope (`req.app.locals`), request scope (`req.body`, `req.query`), session scope (via `express-session`).
- MongoDB intro: NoSQL document store, collections of JSON-like documents, basic `find`/`insert`/`update`/`remove` shell commands; contrast with relational tables.

Exam focus: refactor a monolithic `app.js` into controller + router files; choose the correct scope (app/request/session) for a given variable; translate a relational schema requirement into a MongoDB document/collection design.
