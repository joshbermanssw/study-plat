## Summary

This Week 8 lecture revisits the client side with jQuery as a stepping-stone toward full frontend frameworks, focusing on DOM manipulation and AJAX — the bridge to Week 9's React material.

- jQuery as a cross-browser wrapper over `getElementById`/`querySelectorAll`, event registration, AJAX, and effects; loaded via CDN with a local failsafe.
- Selectors mirroring CSS: `$("*")`, `$("tag")`, `$(".class")`, `$("#id")`, plus filters (`:first`, `:nth-child`); always returns a set.
- Event handling and DOM manipulation: `.on('click', fn)`, `.hide()`, `.html()`, `.append()`, chainable calls.
- AJAX: `$.get`/`$.post`/`$.ajax` for asynchronous JSON exchange with the Express server without a full page reload — foundation of SPA behaviour.
- Integrating jQuery into an Express app: serving the script as a static asset and using it in EJS/Pug views.

Exam focus: convert vanilla DOM code to equivalent jQuery (or vice versa); write a `$.ajax` call against a given Express route; predict the effect of a chained jQuery selector + action on a DOM fragment.
