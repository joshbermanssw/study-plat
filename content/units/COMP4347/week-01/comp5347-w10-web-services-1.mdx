## Summary

This Week 10 lecture covers service-oriented architecture and building/consuming web services in Express.js — the data-exchange layer of the unit.

- SOA: services as the unit of composition, enabling integration across heterogeneous platforms and avoiding rewriting legacy code.
- SOAP: XML-based RPC over HTTP with mandatory `Envelope`/`Body` and optional `Header`; described by WSDL; UDDI for discovery (rarely used).
- REST: resource-centric, uses HTTP verbs (`GET`, `POST`, `PUT`, `DELETE`) and status codes; typically JSON; stateless.
- Creating REST endpoints in Express: route handlers per resource/verb, returning JSON with appropriate status codes.
- Consuming REST services from Express (server-to-server requests) — fetching and forwarding data between services.

Exam focus: contrast SOAP vs REST (transport, payload format, statefulness, discovery); design a RESTful URL scheme and verb mapping for a resource; write or critique an Express route that exposes/consumes a REST endpoint.
