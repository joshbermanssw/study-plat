## Summary

This Week 1 tutorial gives hands-on practice with core JavaScript fundamentals in the browser console and `.html`/`.js` files, anchoring the language layer of the client-side stack used throughout Web Application Development.

- Variable declarations (`var`, `let`, `const`) and how scope differs between function-scoped (`var`) and block-scoped (`let`/`const`) bindings.
- Primitive types (`number`, `bigint`, `string`, `boolean`, `null`, `undefined`, `object`) and dynamic typing inspected with `typeof`; note JS is interpreted and multi-paradigm.
- Operators including `==` (loose, type-coercing) vs `===` (strict, value + type), arithmetic (`%`, `**`), and logical (`&&`, `||`, `!`).
- Control flow: `if`/`else if`/`else`, `switch` (mandatory `break` to avoid fall-through), `for` loops with initialiser/condition/increment, `break`/`continue`.
- Arrays (ordered, 0-indexed) vs Objects (key/value pairs), function declarations, parameters and `return`, plus camelCase naming and `console.log` for output.

Exam focus: predict the output of small JS snippets involving type coercion (`12 + "hello"`), scope, and `==` vs `===`; trace `for` loops with `break`/`continue` or assignment-vs-comparison bugs (e.g. `if (i = 5)`).
