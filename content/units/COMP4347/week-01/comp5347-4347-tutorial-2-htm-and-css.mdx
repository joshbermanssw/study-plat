## Summary

- Semantic sectioning (adding a "Related Photos" section after "Description") and intra-page navigation links via `href="#id"`.
- Reusing existing CSS rules by writing HTML that matches the rule's selector (class, descendant, child).

- Image gallery interaction patterns (click small image, show larger version) using the same conventions as the existing main photo.
- Repeating structural patterns (a second review) so list-style CSS applies uniformly.

Exam focus: given an HTML fragment and a CSS rule, predict whether the rule applies and what the rendered style is; reverse-engineer the selector required to style a given element.
