## Summary

This Week 1 lecture introduces web application architecture and the foundations of how the web works, then bootstraps the JavaScript language — the first technical lecture of the unit.

* Client/server architecture variants: static sites, SPAs, MPAs, WebSocket-based apps; distinction between website (HTML/CSS/JS) and web application (website + server + services).

* "Architecture" in four senses: client/server split, tech stack, infrastructure topology, code patterns.

* Web fundamentals: URLs as resource identifiers, HTTP as request/response protocol, web servers, HTML, browsers (per Berners-Lee's 1990 proposal, W3C since 1994).

* JavaScript primer: variables, types, control flow, functions, objects, arrays, scope.

* IP addresses and DNS-resolved domains underpinning URL-based requests.

Exam focus: classify an app as static/SPA/MPA/WebSocket from its behaviour; identify the role of client, server, and service in a given scenario; basic JS output prediction questions seeded here.
