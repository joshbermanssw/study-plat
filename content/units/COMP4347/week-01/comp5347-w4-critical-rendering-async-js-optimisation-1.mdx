## Summary

This Week 4 lecture explains the browser's critical rendering path and the asynchronous JS / optimisation techniques used to keep it fast — the performance pillar of the client-side material.

- Critical Rendering Path: parse HTML to DOM, parse CSS to CSSOM, combine into render tree (skipping `display: none`), layout, paint.
- Resource fetching during DOM build: `<link>` triggers CSS request, `<img>` triggers image request; CSS blocks rendering, synchronous `<script>` blocks parsing.
- Asynchronous JavaScript: `async`/`defer` script attributes, callbacks, Promises, and the event loop preventing main-thread blocking.
- DevTools Network tab: read waterfall, identify render-blocking resources, `DOMContentLoaded` vs `Load`.
- Optimisations: skeleton screens, progressive rendering, JS minification, preloading, caching headers.

Exam focus: predict the order of DOM/CSSOM/render-tree construction for given markup; identify render-blocking resources and choose `async` vs `defer`; recommend an optimisation given a waterfall.
