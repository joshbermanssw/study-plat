## Summary

Reference cheat-sheet covering the entire `mongosh` command surface — useful for Week 7 (Connecting to a Database), assignments, and any exam question that asks you to write a query.

- **CRUD**: `insertOne` / `insertMany`, `find({filter}, {projection})`, `updateOne` / `updateMany` with `$set` / `$inc`, `replaceOne`, `deleteOne` / `deleteMany`.
- **Query operators**: comparison (`$eq`, `$gt`, `$gte`, `$lt`, `$lte`, `$ne`, `$in`, `$nin`) and update (`$inc`, `$min`, `$max`, `$rename`, `$set`, `$unset`).
- **Cursor modifiers**: `sort`, `limit`, `skip`, `push`. Projection field `1`/`0` toggles inclusion (and explicitly excludes `_id`).
- **Aggregation pipeline**: `aggregate([{$match}, {$group}, {$sort}])`, plus single-purpose `count`, `distinct`, `estimatedDocumentCount`.
- **Ops**: indexes (`createIndex`, `dropIndex`, `getIndexes`), replication (`rs.add`, `rs.status`, `rs.stepDown`), sharding (`sh.shardCollection`, `sh.moveChunk`, `sh.status`), users + roles.

**Exam focus**: most likely tested as "write a query/update/aggregation that does X", or short-answer on the difference between `updateOne` vs `replaceOne` vs `$set`, and when to use sharding vs replication. Memorise the operator names — the rest is composition.
