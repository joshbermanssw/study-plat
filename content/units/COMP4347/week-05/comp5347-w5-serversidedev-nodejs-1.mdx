## Summary

This Week 5 lecture introduces server-side development with Node.js and Express.js plus the MVC pattern — the pivot from client to server in the unit.

- Web server roles: listening for HTTP requests (URL, method, headers, params/body) and returning dynamic vs static responses; static file servers vs application servers.
- Stack components: runtime (Node.js), HTTP framework (Express), templating (EJS/Pug), database (MongoDB/Postgres).
- MVC: Model (data/business rules), View (presentation/templating), Controller (request handling, glue) — separation of concerns so swapping any layer is local.
- Express basics: `app.get/post/put/delete(path, handler)`, `req`/`res`, route parameters, middleware via `app.use`.
- HTML templating: server-rendered views with EJS or Pug, passing data from controller to view.

Exam focus: classify code into M/V/C; design an Express route + handler for a given URL; predict the rendered HTML given a template and controller-supplied data.
