## Summary

This Week 5 tutorial walks through bootstrapping a Node.js + Express.js project from scratch, reinforcing the lecture's server-side fundamentals.

- Verifying Node.js install with `node -v`; downloading LTS from nodejs.org if missing.
- Initialising a project with `npm init` (note: set entry point to `app.js`), which produces `package.json` — the dependency manifest.
- Local vs global install: Express is project-local (`npm install express ejs pug`) rather than OS-wide, behaving as a library.
- Project layout in VS Code: extracting `week5.zip` from Canvas into the project root.
- View engines EJS and Pug installed alongside Express, ready for templating exercises later in the tutorial.

Exam focus: order the commands needed to bootstrap an Express project; explain the role of `package.json` and `node_modules`; distinguish local vs global npm installs and why Express must be local.
