## Summary

This Week 7 lecture covers MongoDB indexing and the Mongoose ODM as the model layer of an Express MVC app — completing the database tier of the unit.

- MongoDB indexes: B-tree structures speeding queries; mandatory unique `_id` index; single-field (`db.coll.createIndex({field:1})`), compound, and multikey indexes; `sparse` and `unique` options.
- Mongoose primitives: Schema (shape + validation), Model (compiled schema, collection handle), Document (instance).
- Mongoose queries mirror the shell: `Model.find`, `findOne`, `updateOne`, `deleteOne`, with chainable `.sort()`/`.limit()`/`.select()` and Promise/`async`-`await` returns.
- Database connection management: `mongoose.connect(uri)`, connection events, pooling — a single shared connection per app process.
- Placing DB code in the model layer of MVC so controllers stay storage-agnostic.

Exam focus: choose the correct index (single/compound, direction) for a given query and sort; write a Mongoose schema + query for a stated requirement; identify why an unindexed query is slow.
