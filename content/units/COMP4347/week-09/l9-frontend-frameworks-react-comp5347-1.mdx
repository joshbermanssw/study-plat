## Summary

This Week 9 guest lecture introduces frontend frameworks generally and React.js specifically, capping the client-side block of Web Application Development.

- CSS/UI vs JS frameworks: Bulma/Bootstrap/Tailwind bundle styles; React/Vue/Angular bundle component logic and state.
- Why frameworks: component-based architecture, state management (Redux for React, Vuex for Vue), automated bundling/minification (Webpack), syntax translation (Babel), package management (npm), increased reusability and testability.
- React core concepts: components (function/class), JSX, props (read-only inputs), state (`useState` for local, Redux for global), and the virtual DOM diffing for efficient re-renders.
- Lifecycle / hooks (`useEffect`) and event handling using camelCase synthetic events.
- Architectural shift: the frontend takes over view-template responsibility from the server, which becomes a JSON API.

Exam focus: contrast a CSS framework with a JS framework; identify props vs state in a component; explain how the virtual DOM avoids unnecessary reflows; design a simple component tree for a given UI.
