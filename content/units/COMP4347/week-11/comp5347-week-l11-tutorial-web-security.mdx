## Summary

This Week 11 tutorial gives hands-on practice with two of the most-tested OWASP vulnerabilities — NoSQL injection in MongoDB and XSS in JavaScript — directly reinforcing the security lecture.

- NoSQL injection: passing operator objects like `{"$gt": ""}` as username/password bypasses naive `find({username, password})` queries because the value is interpreted as a query operator.
- Reproducing the attack with POST `application/json` or `application/x-www-form-urlencoded` payloads (`username[$gt]=&password[$gt]=`) via REST Client / Postman when the browser blocks it.
- Mitigations: validate/sanitise input (cast to string), use parameterised queries, never pass raw `req.body` into a query, escape special characters.
- XSS practice: unescaped user input rendered into the DOM executes attacker-supplied `<script>`; mitigate by output encoding and using `textContent` over `innerHTML`.
- Toolchain: `npm install`, `nodemon`, REST Client / Postman, Mongoose version compatibility.

Exam focus: spot the injection-vulnerable line in a snippet and rewrite it safely; explain why `{"$gt": ""}` bypasses a login; distinguish stored vs reflected XSS and pick the correct mitigation.
