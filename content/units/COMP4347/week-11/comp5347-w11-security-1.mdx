## Summary

This Week 11 lecture covers web application security across server, client, and network — the core security material of the unit.

- Core concepts: authentication (who you are), authorization (what you may do), confidentiality, data integrity.
- Authentication mechanisms: single-factor (password) vs multi-factor (OTP, security questions); local credential stores (DB, LDAP) vs third-party (OAuth, OpenID).
- Authorization: role-based access control (RBAC) mapping users to roles to URL/action permissions, similar to ACLs.
- Cryptography: HTTPS for transport encryption, digital certificates for identity, hashing/salting passwords at rest.
- User-input threats: SQL/NoSQL injection, XSS, CSRF — mitigated by input validation, parameterised queries, output encoding, and CSRF tokens.

Exam focus: identify the OWASP-style vulnerability in a given code snippet (e.g. unescaped query, reflected user input) and propose the correct mitigation; distinguish authentication vs authorization; explain how HTTPS + certificates achieve confidentiality and integrity.
