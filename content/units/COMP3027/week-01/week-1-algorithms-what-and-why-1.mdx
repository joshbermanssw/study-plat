## Summary

Lecture 1 frames the whole unit: how to reason rigorously about correctness and worst-case efficiency, using the maximum-sum contiguous subarray as a running example showing successive O(n^3) → O(n^2) → O(n log n) → O(n) algorithms.

- **Three abstractions:** problem (input/output spec), algorithm (recipe, distinct from implementation), and analysis (proof of correctness + resource bound).
- **Efficiency = polynomial time:** T(n) = a_d n^d + ... + a_0 ⇒ T(n) = Θ(n^d); justifies asymptotic worst-case analysis.
- **Big-O / Ω / Θ definitions:** ∃ c, n_0 such that T(n) ≤ c f(n) for all n > n_0 (and dual for Ω). Master the transitivity, sum, and product rules.
- **Common growth classes:** log n, n, n log n, n^2, n^3, c^n, n! — and the practical implications at n = 10^3–10^6.
- **Input size matters:** number in &#123;1,..,W&#125; costs O(log W) bits; pseudo-polynomial vs polynomial distinction starts here.

**Exam focus:** expect to apply big-O definitions directly (find constants c, n_0), rank functions by growth, or derive a tight Θ-bound from pseudocode by counting nested-loop work.
