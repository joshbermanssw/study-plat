## Summary

Lecture 9 launches the computational-intractability block: polynomial-time (Karp) reductions classify problems by relative difficulty, and the three classical reduction strategies (simple equivalence, special-to-general, gadgets) build the first NP-hardness pipeline.

- **Karp reduction X ≤_p Y:** a poly-time mapping f such that I ∈ X ⇔ f(I) ∈ Y. Transitive. Used to (i) design algorithms or (ii) inherit hardness.
- **Decision ≤_p Optimization ≤_p Search:** justifies focusing on decision problems for reductions.
- **Reduction by simple equivalence:** Vertex Cover ≤_p Independent Set ≤_p Clique via complement / set-complement tricks.
- **Reduction from special case to general:** e.g. Vertex Cover ≤_p Set Cover (let universe = edges, each vertex defines a covering set).
- **Reduction by gadgets:** 3-SAT ≤_p Independent Set — one triangle gadget per clause, conflict edges between literal x and ¬x; clause-set is satisfiable iff IS of size k = # clauses exists.

**Exam focus:** construct a Karp reduction with a small worked example, prove both directions of the "yes-instance ↔ yes-instance" equivalence, and verify the reduction itself runs in polynomial time. Reductions are the dominant proof artefact for the rest of the unit.
