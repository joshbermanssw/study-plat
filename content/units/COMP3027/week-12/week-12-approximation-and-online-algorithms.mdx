## Summary

Final lecture: sacrifice optimality but keep polynomial time — approximation algorithms with provable ratios, plus online algorithms analysed via competitive ratio. Closes the W11 "coping with hardness" arc.

- **Approximation ratio:** for a minimisation problem, ALG ≤ c · OPT for every instance; algorithm is a c-approximation. Need a lower bound on OPT to compare against (weak duality).
- **Unweighted Vertex Cover, 2-approx:** greedily pick both endpoints of any uncovered edge. The selected edges form a matching M; |C| = 2|M| and any vertex cover S must satisfy |M| ≤ |S|, so |C| ≤ 2|S|.
- **Weighted Vertex Cover, pricing method (2-approx):** raise edge prices p_e while no vertex is "tight" (Σ p_e of incident edges = w_i); output all tight vertices. Fairness inequality Σ_e p_e ≤ w(S) for every vertex cover S gives w(C) ≤ 2 · w(OPT). LP-rounding interpretation.
- **Other approximations:** Set Cover ⇒ greedy gives H_n-approximation; metric TSP ⇒ 2-approx via MST doubling; Load Balancing ⇒ 2-approx by list-scheduling, 3/2 by LPT.
- **Online algorithms (competitive ratio):** algorithm must decide irrevocably as input arrives; ratio measured against an offline optimum.

**Exam focus:** prove an approximation ratio by bounding OPT from below (matching, LP relaxation, structural argument) and bounding ALG from above; identify when the analysis is tight via a worst-case family.
