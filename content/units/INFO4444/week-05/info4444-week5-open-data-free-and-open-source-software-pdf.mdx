## Summary

Week 5 lecture on distributed innovation, focused on **Open Data** and **Free and Open-Source Software (FOSS)** as IP and innovation mechanisms within Module 2.

- **Distributed innovation taxonomy**: product platforms, web APIs, crowdsourcing/crowdfunding, open data, FOSS, user innovation, platform ecosystems, accelerators.
- **Open data definition (Open Knowledge Foundation)**: "freely used, modified, and shared by anyone for any purpose"; AU examples — data.gov.au, data.nsw.gov.au, OpenStreetMap.
- **Value of open data**: economic, big-data analytics, business opportunity; self-reinforcing cycle requires policy support and stakeholder protection.
- **FOSS**: source code freely available, modifiable, redistributable; benefits include transparency/trust, lower cost, collaborative bug-fixing, vendor independence, recruitment.
- **IP context**: patent, copyright, trademark, trade secret — open licences (GPL, MIT, Apache, Creative Commons) operate on top of copyright to grant freedoms.

**Exam focus**: short answer defining open data and FOSS, plus an essay weighing benefits and risks of releasing data or code (free-riding, support burden, IP leakage) using a named example like OpenStreetMap or Linux.
