## Summary

Introductory lecture defining cloud computing and positioning AWS in the IaaS/PaaS/SaaS spectrum; it frames the rest of COMP4349 around AWS service consumption and IAM-controlled access.

- **XaaS models**: IaaS (EC2 — control OS/storage/network), PaaS (Elastic MapReduce, App Engine — managed runtime), SaaS (Gmail, Salesforce — vendor manages all). Pricing ranges from per-second to subscription.
- **Global infrastructure**: Regions contain >=2 Availability Zones (isolated data centres with private high-speed links). Replicate across AZs for resiliency; choose Regions for latency/compliance.
- **Core services**: EC2 (VMs), S3 (object storage), RDS (managed DB), CloudFront (CDN), Elastic Load Balancing. Web-shop reference architecture uses LB + multi-AZ EC2 + replicated RDS.
- **Access mechanisms**: Management Console, AWS CLI, language SDKs, and CloudFormation/Terraform blueprints (Infrastructure-as-Code).
- **IAM essentials**: users, groups, policies (JSON, identity- or resource-based), roles. Explicit deny overrides allow; default is implicit deny — follow least privilege. IAM is global.

**Exam focus**: classify a workload across IaaS/PaaS/SaaS, identify the AWS service for a requirement, and read/interpret an IAM JSON policy applying allow/deny precedence rules.
